# b00tyverse

Meta-vendor aggregator for assimilated vendor forks that used to be direct
submodules of [`elasticdotventures/_b00t_`](https://github.com/elasticdotventures/_b00t_).

Each entry here is its own independent repo/history, pulled in as a git
submodule — nothing is merged or subtree'd into this repo. `_b00t_` depends
on `b00tyverse` as a single submodule instead of depending on each of these
directly.

See `_b00t_/b00tyverse-map.skill.tomllm` in the main repo for the broader
b00tyverse ecosystem map (portfolio graph of platforms, client projects, and
assimilated vendor forks with cake provenance).

- [`codebase-memory-mcp-b00t-ir0n-ledg3rr`](https://github.com/PromptExecution/codebase-memory-mcp-b00t-ir0n-ledg3rr) — code-knowledge-graph / structural-queries MCP server
- [`plantuml-server--b00t--togaf--mcp`](https://github.com/PromptExecution/plantuml-server--b00t--togaf--mcp) — PlantUML/TOGAF diagram-rendering MCP server
